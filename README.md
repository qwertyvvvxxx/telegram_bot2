# 🤖 Telegram Bot 

Багатофункціональний Telegram бот з підтримкою AI (Google Gemini), калькулятором площ геометричних фігур та корисними посиланнями.

## 📋 Опис проекту

Цей бот створений на основі бібліотеки **aiogram 3.x** і надає користувачам наступні можливості:
- 💬 **Чат з AI** - інтеграція з Google Gemini 2.5 Flash для інтелектуальних розмов
- 📐 **Калькулятор площ** - обчислення площі квадрата, кола та трикутника
- 🔗 **Корисні посилання** - швидкий доступ до збережених веб-ресурсів
- 🎲 **Випадкове число** - генерація випадкових чисел у заданому діапазоні
- ⚙️ **FSM (Finite State Machine)** - керування станами для складних діалогів

## 🚀 Функціонал

### Команди бота

- `/start` - Запуск бота та відображення головного меню
- `/rn x-y` (або `/random_number x-y`) - Генерація випадкового числа в діапазоні від x до y
  - Приклад: `/rn 1-100` поверне випадкове число від 1 до 100

### Головне меню

Після запуску `/start` користувач бачить 4 кнопки:

1. **links** - Відкриває список корисних посилань:
   - YouTube (плейлист)
   - Restorant (веб-додаток)
   - Fitlife (веб-додаток)

2. **finding area** - Калькулятор площ з вибором фігури:
   - **Square (Квадрат)** - введіть довжину сторони
   - **Circle (Коло)** - введіть радіус
   - **Triangle (Трикутник)** - введіть основу та висоту

3. **chat with Ai** - Активує режим спілкування з Google Gemini:
   - Підтримує багатооборотні діалоги
   - Автоматично розбиває довгі відповіді на частини (до 4000 символів)
   - Кнопка "cancel" для виходу з режиму AI

4. **other** - Додаткові спеціальні кнопки (Button 1-3)

## 🛠️ Технології

- **Python 3.13+**
- **aiogram 3.28.2** - асинхронна бібліотека для Telegram Bot API
- **google-genai 2.7.0** - інтеграція з Google Gemini AI
- **python-dotenv** - управління змінними середовища
- **aiohttp** - асинхронні HTTP запити

## 📦 Встановлення

### 1. Клонуйте репозиторій або завантажте файли проекту

```bash
cd D:\work\telegram_bot2
```

### 2. Створіть віртуальне середовище

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### 3. Встановіть залежності

```powershell
pip install -r requirements.txt
```

### 4. Налаштуйте змінні середовища

Створіть файл `.env` у кореневій папці проекту:

```env
TELEGRAM_TOKEN=your_telegram_bot_token_here
GEMINI_API_KEY=your_gemini_api_key_here
```

#### Як отримати токени:

- **TELEGRAM_TOKEN**: 
  1. Напишіть [@BotFather](https://t.me/BotFather) в Telegram
  2. Створіть нового бота командою `/newbot`
  3. Скопіюйте отриманий токен

- **GEMINI_API_KEY**:
  1. Перейдіть на [Google AI Studio](https://aistudio.google.com/app/apikey)
  2. Створіть API ключ
  3. Скопіюйте ключ у файл `.env`

## ▶️ Запуск

```powershell
python main.py
```

Після успішного запуску в консолі з'явиться повідомлення:

## 🔧 Опис модулів

### `main.py`
Головний файл, який:
- Ініціалізує бота та диспетчер
- Реєструє команди бота в меню Telegram
- Підключає всі роутери з handlers
- Запускає polling (отримання оновлень від Telegram)

### `config.py`
Завантажує змінні середовища з `.env` файлу та створює клієнт для Google Gemini API.

### `keyboards.py`
Визначає всі клавіатури бота:
- `main_kb` - головне меню (reply keyboard)
- `links_kb` - inline кнопки з посиланнями
- `areas_kb` - inline кнопки для вибору фігури
- `special_kb` - додаткові спеціальні кнопки
- `calcel_kb` - кнопка "cancel" для виходу з режимів

### `handlers/commands.py`
Обробляє базові команди:
- `/start` - привітання та головне меню
- `/rn` - генерація випадкових чисел

### `handlers/menu.py`
Обробляє натискання кнопок головного меню та inline кнопок.

### `handlers/area_fsm.py`
FSM для обчислення площ. Використовує стани (`AreaStates`) для покрокового збору даних від користувача.

### `handlers/gemini.py`
Обробляє діалоги з AI:
- Використовує FSM стан `GeminiStates.wait_for_prompt`
- Відправляє запити до Gemini API
- Розбиває довгі відповіді на частини

## 🐛 Можливі проблеми та рішення

### Бот не запускається
- Переконайтеся, що `.env` файл існує і містить правильні токени
- Перевірте, чи активоване віртуальне середовище
- Переконайтеся, що всі залежності встановлені: `pip install -r requirements.txt`

### Gemini не відповідає
- Перевірте правильність `GEMINI_API_KEY`
- Переконайтеся, що API ключ не вичерпав квоту
- Перевірте інтернет-з'єднання

### Помилки кодування в консолі
- У Windows PowerShell можуть виникати проблеми з виводом Unicode
- Додайте на початок `main.py`: 
  ```python
  import sys
  sys.stdout.reconfigure(encoding='utf-8')
  ```
